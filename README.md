### Cómo usarlo en el juego

1. Crea en tu partida un archivo nuevo con el **mismo nombre** que el de aquí (sin `.py`): el juego
   importa los archivos por su nombre.
2. Copia y pega el código.
3. Ejecútalo con ▶.

El lenguaje del juego se parece mucho a Python, pero no es Python: el código está pensado para
ejecutarse dentro del juego.
